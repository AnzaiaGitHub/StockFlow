# StockFlow
Es un proyecto personal a modo de poner en práctica la programación con agentes a través de OpenCode.
Guiando el agente en cada uno de los features para obtener el MVP deseado usando también el control de versiones.
Además, también se busca interactuar con el framework Flutter para desarrollo de aplicaciones móviles ya que es una tecnología vigente en el mercado que se actualiza constantemente.

Para más detalles de cómo correr el proyecto y generar el APK del MVP, visita el README.md de la carpeta /stock_flow
