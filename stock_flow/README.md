## Web build

Run `flutter build web` from this directory. Drift's web database uses the
`sqlite3.wasm` and `drift_worker.js` runtime files in `web/`; keep them aligned
with the `sqlite3` and `drift` versions in `pubspec.lock` when updating those
dependencies.
